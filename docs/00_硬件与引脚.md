# 00 硬件与引脚（M1 测试治具）

> 依据：`IINFO/SCH_线材挤出机-入料传感器+磁编码器-测试治具_2026-11-05.pdf`（V1.0，单页）
> 主控：STM32F103C6T6A（LQFP48，32KB Flash / 10KB RAM，只有 TIM1/TIM2/TIM3，**没有 TIM4**）
> 电机驱动：TMC2209-LA（U6）

## 1. 两颗 MCU 的分工

板上确实有**两颗** C6T6，各自独立（原理图上看不到互联网络），都带自己的晶振、复位、SWD 和串口引出：

| | U1（主控1） | U2（主控2） |
|---|---|---|
| 角色 | 测量主控：PC 通信 + 8 路测试点 + 对射判定 | 电机主控：TMC2209 + 8 路测试点（可与 U1 交叉校验） |
| PC 串口 | USART1：PB6=TX、PB7=RX → 下载口 **H1** | USART1：PB6=TX、PB7=RX → 下载口 **H3** |
| TMC2209 | 不接 | EN=PA0、DIR=PB8、STEP=PB9、单线 UART：PA9(TX)/PA10(RX) |
| 系统灯 | PC13（低电平点亮） | PC13（低电平点亮） |
| 晶振 | 8MHz（PD0/PD1） | 8MHz（PD0/PD1） |

> 网名方向说明：TMC2209 的 `PDN_UART` 直连网络 **TM_RX**（=PA9），另一路经串阻接 **TM_TX**（=PA10）。
> 与 R1 治具一致，这两个网名是"从 TMC 视角"命名的，所以 **PA9 是 MCU 发送、PA10 是 MCU 接收**。
> 固件里做了上电自动换向探测（`BSP_TMC_Probe`），即使方向理解反了也能自动纠正。

## 2. 测试点（ADC 通道映射）

8 个网络 ADC0..ADC7 同时接到 U1 和 U2，但两边的引脚编号不同：

| 网络 | 功能（原理图"测试点功能"表） | U1 引脚 | U1 ADC 通道 | U2 引脚 | U2 ADC 通道 |
|---|---|---|---|---|---|
| ADC0 | 板载 3.3V（直连） | PA3 | IN3 | PB0 | IN8 |
| ADC1 | 3.6V | PA4 | IN4 | PA7 | IN7 |
| ADC2 | 板载 5V（10k/15k 分压，×0.4） | PA5 | IN5 | PA6 | IN6 |
| ADC3 | 磁编码反馈 | PA6 | IN6 | PA5 | IN5 |
| ADC4 | 发光二极管检测1（对射接收1） | PA7 | IN7 | PA4 | IN4 |
| ADC5 | 发光二极管检测2（对射接收2） | PB0 | IN8 | PA3 | IN3 |
| ADC6 | 光电三极管检测1 | PB1 | IN9 | PA2 | IN2 |
| ADC7 | 光电三极管检测2 | PA2 | IN2 | PB1 | IN9 |

- 只有 **ADC2** 有分压：引脚电压 × 25/10 = 实际 5V 电压。其余通道按 1:1 还原。
- 协议里每通道同时给 `raw`、**输入侧 mV**（已做分压还原）、`flags`。

## 3. 对射（through-beam）通道

治具侧两路接收电路：`PT334-6B` 光电三极管，集电极 20k 上拉到 3.3V，发射极接地，输出接 ADC4/ADC5。

- **有光**（光路通）→ 三极管导通 → 电压低
- **被遮挡** → 三极管截止 → 电压接近 3.3V

固件判据（`bsp_sensor.c`）：

| 参数 | 默认值 | 说明 |
|---|---|---|
| 遮挡阈值 `block_mv` | 2000mV | 电压 ≥ 该值 → 判为遮挡 |
| 释放阈值 `release_mv` | 1700mV | 电压 ≤ 该值 → 判为恢复（回差 300mV） |
| 去抖次数 | 3 | 连续 3 次（10ms/次）一致才翻转 |

阈值可用协议 `0x0021` 在线调整，无需重新烧录。

## 4. TMC2209（U2）

| TMC 引脚 | 网络 | MCU 引脚 | 说明 |
|---|---|---|---|
| ENN (pin2) | EN2 | PA0 | **低电平使能**；CubeMX 工程里没有配 PA0，固件在 `BSP_Motor_Init()` 里手工初始化 |
| STEP (pin16) | MCPWM_STEP2 | PB9 | C6T6 没有 TIM4，PB9 无硬件 PWM → **TIM2 中断 + GPIO 翻转** |
| DIR (pin19) | MCPWM_DIR2 | PB8 | 低=CW，高=CCW |
| PDN_UART (pin14) | TM_RX / TM_TX | PA9 / PA10 | 单线半双工，**软件 UART**（TIM3 位定时，115200 8N1） |
| MS1_AD0 / MS2_AD1 | — | 10k 上拉 / 10k 上拉 | 从机地址 = 0b11 = **3**（固件上电扫描 0..3，不写死） |

默认电机参数（`app_config.h` 可改）：

| 项 | 值 |
|---|---|
| 微步 | 16（CHOPCONF.MRES=4）→ 3200 步/圈 |
| IRUN / IHOLD | 16 / 8（≈0.94A / 0.47A，110mΩ 采样电阻） |
| 斩波 | StealthChop2（GCONF.en_SpreadCycle=0）；若板上 SPREAD 引脚被硬件拉低则实际按 SpreadCycle 运行，属正常 |
| 起步/巡航频率 | 500Hz / 命令给定（夹在 500~20000Hz） |
| 加减速 | 各 800 步梯形（行程不足自动降为三角） |

## 5. 下载/调试口

| 接口 | 引脚 | 用途 |
|---|---|---|
| H1 | 1=U1-RX1、2=U1-SWD、3=U1-TX1、4=U1-SCLK | U1 串口 + SWD |
| H3 | 1=U2-TX1、2=U2-SWD、3=U2-RX1、4=U2-SCLK | U2 串口 + SWD |
| H2 | 1=U1-BOOT0、3=U2-BOOT0、2/4=3.3V(R87 10k) | BOOT0 跳线（ISP 升级用） |

## 6. 电源

- 24V 输入 → SY8205FCC 降压到 5.1V（MAX 3A）→ TLV62569 降压到 3.3V（MAX 2A）。
- 测试点 ADC0 直接接 3.3V、ADC2 经分压测 5V，可用来校验板子自身供电与 ADC 基准。
