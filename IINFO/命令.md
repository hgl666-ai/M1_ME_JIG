0. 总览
--------------------------------------------------------------------------------

0.1 帧格式

  偏移   0    1          2            3             4            5           6          7        8 .. 8+L-1     8+L       9+L
         A5   5B   CMD_H  CMD_L  SEQ_H  SEQ_L  LEN_H  LEN_L   DATA...      CRC_H  CRC_L

    +--------+------+----------------------------------------------------------+
    | 字段   | 字节 | 说明                                                     |
    +--------+------+----------------------------------------------------------+
    | 帧头 F |  2   | 固定 A5 5B                                               |
    | 命令 C |  2   | 大端 u16，见第 1 章命令表                                |
    | 序号 N |  2   | 大端 u16，从 1 递增、FFFF 回卷；0 专供"主动帧"（本板暂无）|
    | 长度 L |  2   | 大端 u16，表示 DATA 的字节数（不含帧头/CRC）             |
    | 数据 D |  L   | 见各命令说明                                             |
    | CRC16  |  2   | MODBUS 校验，大端存放                                    |
    +--------+------+----------------------------------------------------------+

    一帧最短 10 字节（L=0）。单帧 DATA 上限 256 字节（固件 FRAME_MAX_DATA）。

0.2 字节序
    所有多字节字段大端（高字节在前）。

0.3 CRC16 规则
    算法    : MODBUS（多项式 0xA001 反射，初值 0xFFFF）
    计算范围: 从"帧头 A5"到"数据 D 的最后一个字节"（不含 CRC 自身）
    存放    : 大端（高字节在前）
    校验失败: 接收方只做诊断计数（自检 0x0030 可见）、不回任何应答，
              发送方靠超时重发。
    自检    : CRC16("123456789") = 0x4B37

0.4 帧序号 N 与 ACK 规则
    1) PC 每发一帧 N 递增（从 1 开始，0xFFFF 后回卷，跳过 0）。
    2) 应答帧的 N 等于请求帧的 N（ACK 回显）。
    3) 本板当前没有主动上报帧；如以后增加，N 固定用 0。
    4) N 非递增**不拒绝**，只做告警计数（协议表 ERR_SEQ 仅警告）。
    5) 命令码未定义 → 回 FF（NIY，未实现），不静默丢弃。
    6) 串口助手手工测试可以一直用 N=0001，不影响功能。

0.5 状态码总表（ACK 的 DATA[0]）

    +------+------------------+------------------------------------------------+
    | 码   | 名称             | 本板出现场景                                   |
    +------+------------------+------------------------------------------------+
    | 0x00 | OK               | 成功                                           |
    | 0x01 | BUSY             | 电机运动中的 MOVE；运动中的 TMC 查询/设电流    |
    | 0x02 | ERR_SIZE         | 预留（本板无文件传输）                         |
    | 0x03 | ERR_FLASH        | 预留                                           |
    | 0x04 | ERR_PROG         | 预留                                           |
    | 0x05 | ERR_TEST         | 自检有项未通过（见 0x0030 位图）                |
    | 0x06 | ERR_NO_FW        | 预留                                           |
    | 0x07 | ERR_INCOMPLETE   | 预留                                           |
    | 0x08 | ERR_CRC          | 帧 CRC 错误（仅诊断，不回 ACK）                |
    | 0x09 | ERR_SEQ          | 帧序号非递增（仅告警，不拒绝）                 |
    | 0x0A | ERR_COUNT        | 预留                                           |
    | 0x0B | ERR_PARAM        | 参数错误（mode 非法 / 长度不对 / 阈值非法）    |
    | 0x0C | ERR_TIMEOUT      | 预留                                           |
    | 0x0D | ERR_OVERFLOW     | 预留                                           |
    | 0xFF | NIY              | 命令未实现                                     |
    +------+------------------+------------------------------------------------+

0.6 链路与角色

    PC ↔ U2 : USART1（PB6=TX / PB7=RX），115200 8N1，无流控；接 H3 下载口。
              U2 是唯一的执行者：既测 ADC/对射，也驱动电机。
    U1      : 本板另一颗 MCU，引脚只有 ADC/USART1/SWD/LED，**不能驱动电机**
              （EN/STEP/DIR 只接到 U2）。当前不烧录，H1 口无应答。
    H3 引脚 : 1=U2-TX1  2=U2-SWD  3=U2-RX1  4=U2-SCLK
              ⚠ 与 H1 是镜像的：H1 的 pin1 是 RX，H3 的 pin1 是 TX。
              ⚠ H1/H3 都没有 GND 针，GND 要从 24V 输入座或测试点排针取。

1.1  0x0001  PING（链路探测）
--------------------------------------------------------------------------------
功能      : 确认串口通、固件在跑。上位机"连接设备"用，最便宜的一条。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 01
帧序号    : N（PC 递增；ACK 回显）
数据长度  : 00 00
数据      : 无（LEN 必须为 0）
CRC16     : MODBUS，覆盖 帧头..数据末字节，大端
ACK 内容  : 命令 00 01；帧序号 = N；长度 00 01；数据 = 1 字节状态码
            状态码：00 OK
示例      : N=1
            PC → : A5 5B 00 01 00 01 00 00 89 0C
            U2 → : A5 5B 00 01 00 01 00 01 00 95 88
备注      : 1) 无副作用，任何状态都能问（不受 BUSY 限制）。
            2) 没有应答时先查：是否接 H3、TX/RX 是否交叉、是否共地、波特率。

--------------------------------------------------------------------------------
1.2  0x0002  查询固件版本
--------------------------------------------------------------------------------
功能      : 读 U2 固件版本号（主/次/修订）。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 02
帧序号    : N
数据长度  : 00 00
数据      : 无
CRC16     : 同上
ACK 内容  : 命令 00 02；帧序号 = N；长度 00 04；
            数据 = [0] 状态码 00 + [1] 主 + [2] 次 + [3] 修订
示例      : N=1，v1.0.0
            PC → : A5 5B 00 02 00 01 00 00 89 48
            U2 → : A5 5B 00 02 00 01 00 04 00 01 00 00 4A 66
备注      : 当前版本 1.0.0；改版本号见 U1/U2 的 Core/Inc/app_config.h
            （FW_VER_MAJOR/MINOR/PATCH）。

--------------------------------------------------------------------------------
1.3  0x0003  读 96bit 唯一 ID
--------------------------------------------------------------------------------
功能      : 读 STM32 出厂 96bit UID（0x1FFFF7E8），用于板子身份/SN 追溯。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 03
帧序号    : N
数据长度  : 00 00
数据      : 无
CRC16     : 同上
ACK 内容  : 命令 00 03；帧序号 = N；长度 00 0D（= 13）；
            数据 = [0] 状态码 00 + [1..12] 12 字节 UID（原序，未做字节序调整）
示例      : N=1
            PC → : A5 5B 00 03 00 01 00 00 49 75
            U2 → : A5 5B 00 03 00 01 00 0D 00 <12B UID> <CRC>
备注      : UID 每颗芯片唯一；PC 侧可直接当设备序列号入库。

--------------------------------------------------------------------------------
1.4  0x000E  测量 8 路测试点 ADC
--------------------------------------------------------------------------------
功能      : 读/测 8 路测试点：3.3V、3.6V、5V、磁编码反馈、2 路对射、
            2 路光敏三极管。每路同时给 raw、输入侧 mV、flags。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 0E
帧序号    : N
数据长度  : 00 01
数据      : [0] 模式：00 = 只读（立刻回后台最近一轮快照，不触发采集）
                    01 = 触发一轮（8 路 × 8 次平均，约 1.5ms 后回）
            其它值 / LEN=0 → 回 0B ERR_PARAM
CRC16     : 同上
ACK 内容  : 命令 00 0E；帧序号 = N；长度 00 33（= 51）；
            数据布局见下表（全部大端）
示例      : 触发测量，N=1
            PC → : A5 5B 00 0E 00 01 00 01 01 AA 49
            U2 → : A5 5B 00 0E 00 01 00 33 | 51 字节 | CRC
            只读快照，N=1
            PC → : A5 5B 00 0E 00 01 00 01 00 6A 88
备注      : 1) 后台快照每 200ms 自动刷新一次；mode=00 返回的就是这一批。
            2) 8 路采集约 1.5ms，200ms 周期下 CPU 占用约 0.75%。
            3) ADC2（板载 5V）已按 10k/15k 分压还原，报文里的 mV 是**输入侧**
               的实际 5V 电压；其余通道 mV 就是引脚电压。
            4) flags：bit0 有效 / bit1 贴边（raw≤4 或 ≥4091）/ bit2 对射通道。
            5) ADC0 直连 3.3V，raw 在 4088~4095 之间，**贴边位可能为 1 也可能
               为 0（取决于 VDDA）**，两种都正常，不参与合格判定。

ACK 数据 51 字节布局：

    偏移  长度  字段            说明
    ----  ----  --------------  ----------------------------------------------
      0     1   状态码          00 OK / 0B 参数错
      1     1   flags           bit0 快照有效 / bit2 VDDA 已校准（正常 0x05）
      2     1   通道数          固定 08
      3     2   回合号          每次刷新 +1（u16）
      5     2   耗时 ms         本轮 8 路采集耗时（正常 1~3）
      7     2   VDDA mV         校准后的 3.3V 轨电压（正常 3200~3400）
      9     2   配置指纹        0x05（239.5 周期）<< 8 | 平均次数（0x0508）
     11     8×5 通道数据        顺序 ADC0..ADC7，每通道：
                                   +0  2  raw   12bit 原始值
                                   +2  2  mv    输入侧电压（ADC2 已 ×2.5 还原）
                                   +4  1  flags 同上面的通道 flags

    通道顺序与功能见附录 A。

--------------------------------------------------------------------------------
1.5  0x000F  读对射传感器状态
--------------------------------------------------------------------------------
功能      : 读两路对射的原始值、当前阈值和"遮挡/通光"结论。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 0F
帧序号    : N
数据长度  : 00 01
数据      : [0] 模式：00 = 读最近一次轮询结果
                    01 = 立即采一次（忽略 10ms 限速）
            其它值 / LEN=0 → 回 0B ERR_PARAM
CRC16     : 同上
ACK 内容  : 命令 00 0F；帧序号 = N；长度 00 14（= 20）；数据布局见下
示例      : N=1
            PC → : A5 5B 00 0F 00 01 00 01 00 BB 89
            U2 → : A5 5B 00 0F 00 01 00 14 | 20 字节 | CRC
备注      : 1) 两路对应 ADC4（ch1）/ ADC5（ch2），即治具侧 PT334 接收管。
            2) 判定是"连续 3 次（30ms）一致才翻转"，遮挡后请稍等再读。
            3) 采样失败时只清 valid 位，保留上一次结论，不会误判。

ACK 数据 20 字节布局：

    偏移  长度  字段            说明
    ----  ----  --------------  ----------------------------------------------
      0     1   状态码          00 OK / 0B 参数错
      1     1   flags           bit0 两路都有效 / bit1 ch1 遮挡 / bit2 ch2 遮挡
      2     9   ch1 数据         +0 2 raw / +2 2 mv / +4 2 block_mv
                                 +6 2 release_mv / +8 1 blocked(1=遮挡)
     11     9   ch2 数据         同 ch1

    通光 → mv 低（几百 mV）、blocked=0；遮挡 → mv 高（2.5~3.3V）、blocked=1。

--------------------------------------------------------------------------------
1.6  0x0010  电机定长运动
--------------------------------------------------------------------------------
功能      : 让电机按给定方向走指定步数，带梯形加减速；非阻塞，立即回 ACK。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 10
帧序号    : N
数据长度  : 00 07
数据      : [0]    1 字节 dir：00 = CW，01 = CCW
            [1..4] 4 字节 steps（u32，大端）：1 ~ 100000000
            [5..6] 2 字节 freq_hz（u16，大端）：500 ~ 20000
            长度 < 7 / dir>1 / steps=0 / freq 越界 → 0B ERR_PARAM
CRC16     : 同上
ACK 内容  : 命令 00 10；帧序号 = N；长度 00 01；数据 = 1 字节状态码
            状态码：00 已启动 / 01 BUSY（上一段没停）/ 0B 参数错
示例      : 正转 200 步 @1000Hz，N=1
            PC → : A5 5B 00 10 00 01 00 07 00 00 00 00 C8 03 E8 C3 2F
            U2 → : A5 5B 00 10 00 01 00 01 00 D4 8B
            运动中再发一条 → 01 BUSY：
            U2 → : A5 5B 00 10 00 01 00 01 01 14 4A
备注      : 1) 非阻塞：ACK 只表示"已受理"，进度用 0x0012 查。
            2) 步数单位是 16 微步，3200 步 = 1 圈。
            3) 起步 500Hz，加减速各最多 800 步（行程不足自动降为三角曲线）。
            4) 到位后只停脉冲、EN 保持使能（IHOLD 保持力矩）；
               要脱机发 0x0011。
            5) 首次测试建议先用 0x0022 设小电流。

--------------------------------------------------------------------------------
1.7  0x0011  电机停止/脱机
--------------------------------------------------------------------------------
功能      : 立刻停止当前运动，并拉高 EN 脱机（释放保持力矩）。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 11
帧序号    : N
数据长度  : 00 00
数据      : 无
CRC16     : 同上
ACK 内容  : 命令 00 11；帧序号 = N；长度 00 01；数据 = 状态码 00 OK
示例      : N=1
            PC → : A5 5B 00 11 00 01 00 00 4A CD
            U2 → : A5 5B 00 11 00 01 00 01 00 05 8A
备注      : 1) 停止后 done 保留在"已走步数"，target 被改写成 done。
            2) 空闲时发也回 OK（幂等）。
            3) 停机后电机没有保持力矩，重力负载可能下滑。

--------------------------------------------------------------------------------
1.8  0x0012  电机状态
--------------------------------------------------------------------------------
功能      : 查是否在运动、已走步数、目标步数。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 12
帧序号    : N
数据长度  : 00 00
数据      : 无
CRC16     : 同上
ACK 内容  : 命令 00 12；帧序号 = N；长度 00 0A（= 10）；
            数据 = [0] 状态码 00
                   [1] busy（1=运动中）
                   [2..5] done（u32，已走步数）
                   [6..9] target（u32，目标步数）
示例      : 已走完 200 步，N=1
            PC → : A5 5B 00 12 00 01 00 00 4A 89
            U2 → : A5 5B 00 12 00 01 00 0A 00 00 00 00 00 C8 00 00 00 C8 3A 59
备注      : 运动中 busy=1、done 递增；到位后 busy=0、done=target。
            0x0011 停止后 target 会被改成 done。

1.9  0x0020  TMC2209 寄存器快照
--------------------------------------------------------------------------------
功能      : 查 TMC2209 是否在线、配置是否生效，并读 4 个关键寄存器。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 20
帧序号    : N
数据长度  : 00 00
数据      : 无
CRC16     : 同上
ACK 内容  : 命令 00 20；帧序号 = N；长度 00 11（= 17）；
            数据布局见下
示例      : 通信与配置都正常，N=1
            PC → : A5 5B 00 20 00 01 00 00 8E B0
            U2 → : A5 5B 00 20 00 01 00 11 00 01 01 00 00 01 D0
                   14 01 01 C3 00 00 00 00 00 00 9A EF
备注      : 1) 电机运动期间发这条会回 01 BUSY（读寄存器会挤占 STEP 中断）。
            2) 通信失败时 alive=0、寄存器字段全 0。
            3) 期望值：GCONF ≈ 0x000001D0、CHOPCONF = 0x140101C3（16 微步）。
            4) DRV_STATUS 低 8 位为过温/短路/开路标志，正常应为 0。

ACK 数据 17 字节布局：

    偏移  长度  字段          说明
    ----  ----  ------------  -------------------------------------------------
      0     1   状态码        00 OK / 01 BUSY
      1     1   alive         1 = 读到寄存器（通信成功）
      2     1   cfg_ok        1 = 关键寄存器写后读回校验通过
      3     4   GCONF         期望 0x000001D0
      7     4   CHOPCONF      期望 0x140101C3（TOFF3/HSTRT4/HEND1/TBL2/MRES4）
     11     4   DRV_STATUS    低 8 位：ot/otpw/s2ga/s2gb/s2vsa/s2vsb/ola/olb
     15     2   SG_RESULT     低 10 位，静止时≈0

--------------------------------------------------------------------------------
1.10  0x0021  设置对射阈值
--------------------------------------------------------------------------------
功能      : 在线修改某一路对射的遮挡/释放阈值，不用重烧固件。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 21
帧序号    : N
数据长度  : 00 05
数据      : [0]    1 字节 通道号：00 = ch1，01 = ch2
            [1..2] 2 字节 block_mv（u16，大端）：遮挡阈值
            [3..4] 2 字节 release_mv（u16，大端）：释放阈值
            校验：LEN≥5、ch<2、release_mv < block_mv、block_mv ≤ 3300
            任一不满足 → 0B ERR_PARAM，旧参数保持不变
CRC16     : 同上
ACK 内容  : 命令 00 21；帧序号 = N；长度 00 01；数据 = 状态码
            00 OK / 0B ERR_PARAM
示例      : ch1 设 2000/1700（默认值），N=1
            PC → : A5 5B 00 21 00 01 00 05 00 07 D0 06 A4 F4 39
            U2 → : A5 5B 00 21 00 01 00 01 00 F5 8F
            非法（release ≥ block）：
            PC → : A5 5B 00 21 00 01 00 05 00 05 DC 07 08 A2 F9
            U2 → : A5 5B 00 21 00 01 00 01 0B 32 CE
备注      : 1) 写入后去抖计数清零，最多 30ms 生效；改完等 50ms 再读 0x000F。
            2) **阈值只存在 RAM，掉电/复位恢复默认 2000/1700**，每次上电需重发。
            3) 默认回差 300mV；建议 release = block − 300 左右。
            4) 标定方法见附录 C。

--------------------------------------------------------------------------------
1.11  0x0022  设置电机电流
--------------------------------------------------------------------------------
功能      : 在线修改 TMC2209 的运行/保持电流（IRUN/IHOLD）。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 22
帧序号    : N
数据长度  : 00 02
数据      : [0] 1 字节 irun：0 ~ 31
            [1] 1 字节 ihold：0 ~ 31，且必须 ≤ irun
            越界 → 0B ERR_PARAM
CRC16     : 同上
ACK 内容  : 命令 00 22；帧序号 = N；长度 00 01；数据 = 状态码
            00 OK / 01 BUSY（电机运动中）/ 0B ERR_PARAM
示例      : IRUN/IHOLD = 12/6，N=1
            PC → : A5 5B 00 22 00 01 00 02 0C 06 A6 F2
            U2 → : A5 5B 00 22 00 01 00 01 00 C6 8F
备注      : 1) 电流 ≈ (IRUN+1)/32 × 1.768A（110mΩ 采样电阻、VSENSE=0）。
                IRUN=12 ≈ 0.72A，IRUN=16 ≈ 0.94A。
            2) 默认 16/8；电机额定未知时先小后大。
            3) 运动中改电流会回 BUSY，等停了再设。

--------------------------------------------------------------------------------
1.12  0x0030  综合自检
--------------------------------------------------------------------------------
功能      : 一次问清 ADC/对射/VDDA/TMC/电机/串口/CRC 七项状态。
发送方    : PC
接收方    : 治具 U2
帧头      : A5 5B
命令      : 00 30
帧序号    : N
数据长度  : 00 00
数据      : 无
CRC16     : 同上
ACK 内容  : 命令 00 30；帧序号 = N；长度 00 06；数据 6 字节：
            [0] 状态码：00 全部通过 / 05 有位没过
            [1] mask（位图，见下）
            [2..3] VDDA mV（u16）
            [4] 贴边掩码（bit0=ADC0 … bit7=ADC7）
            [5] 帧 CRC 错误计数（0~255 饱和）
示例      : 空夹具、未接电机（N=1）
            PC → : A5 5B 00 30 00 01 00 00 4D 71
            U2 → : A5 5B 00 30 00 01 00 06 05 EF 0C E4 00 00 0A D6
            （状态 05 = 有位没过；mask EF = 只有 bit4 TMC 没过；
              VDDA 0C E4 = 3300mV；贴边 00；CRC 错 00）
备注      : 1) mask 位定义见附录 B；`状态 = 00` 要求低 7 位全 1。
            2) **没接电机/TMC 不通时 bit4=0 是正常的**，其余位应全 1。
            3) ADC0 直连 3.3V，贴边掩码 bit0 可能为 1，不参与判定。

附录 C  对射阈值标定
--------------------------------------------------------------------------------
  1) 保持 DUT 上电、光路透光，读 0x000F → 记 low（通光 mV）。
  2) 人为遮挡光路，再读 → 记 high（遮挡 mV）。
  3) 计算：
         block   = low + 0.6 × (high − low)
         release = low + 0.4 × (high − low)
     例：low=350、high=3150 → block=2030、release=1470
  4) 发 0x0021 写入（ch0/ch1 分别设）。
  5) 反复遮挡/松开，确认 0x000F 的 blocked 稳定翻转。
  6) 判据：
         high − low ≥ 1.5V  → 默认 2000/1700 直接可用
         0.5~1.5V          → 按上面公式重设
         < 0.5V            → 光路/灯珠/接收管对准问题，别调阈值

  注意：阈值只在 RAM，掉电恢复默认；每次上电要重发（或后续加 Flash 保存）。
